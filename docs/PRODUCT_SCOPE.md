# 产品范围（PRODUCT_SCOPE）

**产品：** Global Narrative Intelligence（GNI）  
**文档语言：** 中文  
**版本：** Phase 0 冻结稿  
**依据：** Blueprint V2

---

## 1. 产品一句话

GNI 是全球**官方媒体与政府传播机构**舆论信号采集与叙事监测研究系统：持续采集、结构化分析、可追溯比较各国媒体如何描述中国及相关议题。

---

## 2. 研究视角与底层模型

| 层面 | 约定 |
|------|------|
| 首期研究视角 | 中国中心（China-centric） |
| 底层数据模型 | 不写死「仅中国」；支持扩展任意国家、议题与目标对象 |
| MVP 国家短名单 | US、RU、DE、IN、AU |
| 扩展池（非 MVP） | 加拿大等，后续按可采集性纳入 |

---

## 3. Phase 边界

### Phase 1 / MVP（必须）

- 来源注册、分类、审核与停用
- 稳定采集与入库（优先 RSS/API）
- 正文提取、清洗、语言识别、UTC 时间标准化、基础去重
- 文章级：主题、情感、目标对象立场、叙事框架、实体、证据
- 基础统计、Dashboard、日报/周报
- 数据质量面板与 LLM 成本监控

### Phase 2（非 MVP）

- 跨语言转载识别
- 事件识别与动态聚类、生命周期与关系
- 跨国事件叙事差异
- 历史基线、Narrative Shift、基础异常检测

### Phase 3（非 MVP）

- 研究型 Agent、多步骤专题研究
- 证据验证器与正式报告工作流增强
- 可配置综合指数与复杂风险分析

---

## 4. MVP 明确不做

- 不代表某国全部媒体或社会舆论
- 不推断国家真实意图或外交决策
- 不预测战争、政变或外交冲突
- 不直接测量公众民意
- 不无差别抓取全球数百来源
- 不强行采集强反爬 / 登录 / 付费墙 / 条款不明站点
- 不对每篇文章默认执行高成本深度 LLM 分析
- 不提供黑盒单一综合舆情总分
- 不实现完整事件聚类、Narrative Shift、研究型 Agent

---

## 5. 数据源类别（不可默认等价）

1. State-owned / State-controlled Media  
2. Public Service Media  
3. Government Communication Sources  
4. Mainstream Independent Media（后续对照组）

MVP 优先 1–3 类；公共广播不得仅因「公共」归为政府控制媒体。分类须有证据与审核记录。

---

## 6. 首批接通顺序

**美 → 俄 → 德 → 印 → 澳**

俄、印在可达性、语言与合规上标高风险；不得为凑数降低准入标准。Phase 0 仅维护候选与评估流程，**不编造**已验证 feed。
