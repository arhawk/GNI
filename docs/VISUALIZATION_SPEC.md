# 可视化规格（VISUALIZATION_SPEC）

**版本：** 0.1  
**原则：** 按研究问题组织页面；不把所有指标挤进一张图。

---

## 1. MVP 页面

### 1.1 全球总览

**问题：** 这周/这个月各国主要关注哪些议题？

| 视图 | 推荐图形 | 说明 |
|------|----------|------|
| 主题分布 | 堆叠条形图 | 主视图，比较各国主题构成 |
| 主题占比 | Treemap / 占比图 | 单窗口结构 |
| 跨期主题 | 堆叠面积 / 分组柱 | 时间变化 |
| 重点文章 | 表格 | 可回溯原文 |
| 热点摘要 | 主题聚合列表 | 真事件聚类在 Phase 2 |
| 国家覆盖 | 小条形/表 | 样本范围 |
| 质量摘要 | 状态组件 | 防采集问题误读为舆情 |

### 1.2 国家分析

- 情感分布：堆叠条或 100% 堆叠条  
- 立场分布：**独立**堆叠条（按 Target 可切换）  
- 框架分布：基础分布先行  
- 主题 × 框架热力图：样本足够后或 Phase 2  
- 趋势图必须显示 **样本量**  

情感与立场**不得**共用一张含义不清的图。

### 1.3 数据质量

国家来源数、治理属性摘要、采集成功率、正文提取率、发布时间完整率、语言识别、重复比例、分析成功率、待分析队列、Token/费用、来源最近成功时间。  

**与舆情结论分区展示。**

### 1.4 报告

日报、周报列表；统计窗口、时区、来源范围；关键结论证据链接；样本不足提示；版本与证据快照。

---

## 2. Phase 2 页面（预告）

事件列表、时间线、报道强度、国家/来源覆盖、各国情感/立场/框架差异、事件关系。  
地图仅作地理辅助，不替代列表与时间线。

---

## 3. 通用约束

1. 图表标注：时间窗口、时区、样本量、去重口径、metric 版本  
2. 不用一张图混合主题+情感+立场+框架  
3. 来源/国家覆盖属质量信息，不与「叙事结论」混排主视觉  
4. 冷启动期隐藏或降权「异常/风险」类视觉编码  
5. Dashboard 技术选型：Streamlit（MVP）  

---
